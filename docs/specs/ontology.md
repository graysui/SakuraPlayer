# SakuraPlayer 领域词汇

**创建日期**: 2026-07-24

**最后更新**: 2026-07-24

**状态**: Frozen for v1

## 1. 统一词汇

| 术语 | 定义 | 所属上下文 |
|---|---|---|
| 管理员 | SakuraPlayer 唯一的产品用户；不是 115 账号 | 身份与配置 |
| 初始化口令 | 只在尚无管理员时验证的一次性启动级 secret；不写数据库，创建管理员后失去作用 | 身份与配置、交付 |
| 后端基址 | 客户端本机保存的 SakuraPlayer API 地址；不是账号或共享服务端配置 | 客户端体验 |
| 115 绑定 | 唯一 115 账号的加密凭据、账号稳定标识和专属缓存根 CID | 身份与配置、115 播放缓存 |
| AVdb 来源帖子 | AVdb CSV 中由 `website + tid` 唯一标识的一条资源记录 | 资源接入 |
| 原始资源 | AVdb 来源帖子的持久化副本，包含原始番号、分类、大小和加密磁力 | 资源接入 |
| 影片 | 按规范化番号去重的目录聚合；一部影片可以有多个来源帖子 | 目录与元数据 |
| 规范化番号 | 用于影片聚合、精确搜索和刮削的标准番号表示 | 资源接入、目录与元数据 |
| 待识别资源 | 缺少可用番号或无法可靠规范化、尚未关联影片的来源帖子 | 资源接入 |
| 来源标签 | 从明确字段推导、可叠加的字幕、破解、4K、有码等属性 | 资源接入 |
| 破解 | 仅指 `category=无码破解` 或标题明确包含无码破解的来源属性；不是亚洲无码的同义词 | 资源接入 |
| 资源大小 | AVdb `size`，表示磁力资源包大小，离线前使用 | 资源接入 |
| 视频文件大小 | 115 完成后枚举到的具体视频文件字节数 | 115 播放缓存 |
| 来源拒绝标记 | 不含磁力正文、按来源帖子唯一保存的永久拒绝记录，阻止再次导入 | 资源接入 |
| 核心元数据 | JavDB 影片主记录及影片-女优等核心关系；成功后影片可展示 | 目录与元数据 |
| 可选富化 | DMM 简介、图片补齐、GFriends 和 AI 翻译；失败不隐藏影片 | 目录与元数据 |
| 元数据任务 | 对一个规范化番号执行核心刮削和可选富化的持久任务 | 目录与元数据 |
| 手动重试 | 管理员对失败任务创建完整新尝试，或对 warning 任务创建只含明确可选阶段的新尝试；不是 worker 自动重跑 | 目录与元数据 |
| 女优 | UI 对女性演员的显示名称；后端统一实体名为演员 | 目录与元数据、客户端体验 |
| 演员 | 由 JavDB ID 等权威标识识别的自然人目录实体 | 目录与元数据 |
| 权威别名 | 来自 JavDB 或演员映射表的名字；用户搜索词不是别名 | 目录与元数据 |
| GFriends 索引 | Filetree.json 的本地持久索引，只保存映射和 URL | 目录与元数据 |
| GFriends 资产 | GFriends 提供的头像或写真 URL；服务端不全量镜像 | 目录与元数据、客户端体验 |
| 永久目录图片 | 影片封面、剧照和需要持久保存的目录图片副本 | 目录与元数据 |
| 翻译记录 | 原文、译文、来源摘要、模型和提示版本的幂等结果 | 目录与元数据 |
| 排行榜快照 | 某榜单、周期和可选年份最近一次成功同步的有序结果 | 发现 |
| 收藏 | 管理员对影片或女优的单一布尔收藏关系 | 发现 |
| 播放请求 | 用户选择具体来源并点击播放的动作；这是允许离线的唯一入口 | 115 播放缓存 |
| 缓存任务 | 把一个来源离线到 115 专属任务目录并维护生命周期的持久状态机 | 115 播放缓存 |
| 立即任务 | 创建时获得 2 个运行槽之一、客户端最多全屏等待 60 秒的缓存任务 | 115 播放缓存 |
| 排队任务 | 未获得运行槽、计入固定 10 个队列上限且不会阻塞客户端的缓存任务 | 115 播放缓存 |
| 后台继续 | 客户端等待 60 秒结束后，115 和后端仍继续对账该任务 | 115 播放缓存 |
| 专属缓存根 | 115 中名为 `SakuraPlayer-Cache` 的唯一受管根目录 | 115 播放缓存 |
| 任务目录 | 专属缓存根下由一次缓存任务拥有的独立子目录 | 115 播放缓存 |
| 受管目录证明 | 账号、根 CID、任务 CID、当前父 CID 和数据库 owner 的组合证据 | 115 播放缓存 |
| 就绪缓存 | 已完成、已解析出可播放文件且可创建播放会话的缓存任务 | 115 播放缓存 |
| 缓存租约 | 播放期间阻止 TTL/LRU 清理的短期服务器记录 | 播放 |
| 滑动 TTL | 每次有效访问从服务器时间重新计算的缓存过期时间 | 115 播放缓存 |
| LRU | 超过就绪上限时按最后访问时间选择最久未访问且无租约的缓存 | 115 播放缓存 |
| 远端媒体 | 任务目录内一个有效视频文件的稳定 `file_id/pickcode` 定位 | 115 播放缓存 |
| 分段队列 | 能明确识别为连续 CD/part 的多个远端媒体按顺序组成的播放序列 | 115 播放缓存、播放 |
| 播放会话 | 每次点击播放签发的 12 小时能力，绑定影片、缓存、媒体、模式、UA 和管理员会话 | 播放 |
| 原画模式 | 优先由 115 `downurl` 产生的原始文件直链 | 播放 |
| 兼容播放 | 用户主动切换或原画取链失败时使用的最高码率 115 HLS | 播放 |
| 固定 User-Agent | Windows 或 HarmonyOS 平台固定的播放器 UA，签发和后续请求必须一致 | 播放、客户端体验 |
| 字幕副本 | 从 115 下载到客户端应用私有目录、随缓存/登录生命周期删除的文件 | 播放、客户端体验 |
| 影片级进度 | 绑定影片而非某个临时文件的续播状态，可跨客户端同步 | 播放 |
| 已看完 | 播放达到 95% 或剩余不足 2 分钟的影片级状态 | 播放 |
| 任务快照 | REST 返回的当前完整任务状态，用于首次加载或 WebSocket 重连恢复 | 客户端体验 |
| 任务事件 | 后端事务提交后写入的版本化变化通知，可按事件 ID 去重 | 客户端体验 |
| 真实 115 门禁 | 使用专用真实账号验证扫码、离线、播放、字幕与清理的发布条件 | 交付 |

## 2. 禁止混用

| 禁止混用 | 正确表达 |
|---|---|
| “资源”与“影片” | 资源是来源帖子；影片是按番号聚合的目录实体 |
| “资源大小”与“视频文件大小” | 前者来自 AVdb；后者来自 115 实际文件 |
| “亚洲无码”与“破解” | 只有明确子分类或标题证据才标为破解 |
| “缓存任务”与“115 远端任务” | 前者是本地业务状态机；后者是其一个外部关联 |
| “离线完成”与“可播放” | 完成后还必须枚举并选择有效视频文件 |
| “等待超时”与“任务失败” | 60 秒是客户端等待上限；后台任务继续 |
| “签名播放 URL”与“115 直链” | 前者是 SakuraPlayer 能力入口；后者只在重定向时短暂解析 |
| “女优”与“演员 ID” | 女优是显示语汇；关系必须使用演员实体 ID |
| “收藏”与“播放列表” | v1 只有影片/女优单一收藏，不提供自定义列表 |
| “元数据失败”与“影片不可见” | 只有核心元数据未完成才不可见；可选富化失败不隐藏 |

## 3. 限界上下文

| 上下文 | 关键聚合 | 对外发布内容 |
|---|---|---|
| 身份与配置 | 管理员、刷新会话、115 绑定、加密配置 | 认证状态、脱敏配置状态 |
| 资源接入 | 同步批次、原始资源、拒绝标记 | 来源 ID、规范化番号、来源标签 |
| 目录与元数据 | 影片、演员、元数据任务、翻译 | `core_ready` 影片详情、演员资料、任务状态 |
| 发现 | 排行榜快照、收藏 | 过滤后的影片/女优列表和榜单 |
| 115 播放缓存 | 缓存任务、远端媒体、字幕定位 | 任务快照、就绪媒体选择 |
| 播放 | 播放会话、缓存租约、影片级进度 | 签名流入口、字幕选项、进度 |
| 客户端体验 | 本机会话、页面状态、私有缓存 | 用户操作和平台通知 |

## 4. 概念关系

```text
AVdb 来源帖子 N ---- 0..1 影片
影片 1 ---------------- N AVdb 来源帖子
影片 N ---------------- N 演员
影片 1 ---------------- N 元数据任务尝试
影片 1 ---------------- N 排行榜条目
影片/演员 1 ----------- 0..1 收藏

AVdb 来源帖子 1 ------- N 缓存任务
缓存任务 1 ------------ 1 任务目录
缓存任务 1 ------------ N 远端媒体
远端媒体 1 ------------ N 远端字幕定位
缓存任务 1 ------------ N 播放会话
播放会话 1 ------------ 0..1 缓存租约
影片 1 ---------------- 0..1 影片级进度
```

“一个来源可以产生多个历史缓存任务”用于保留失败和清理审计；同一来源同时只能有一个排队、运行或就绪的活动任务。

## 5. 状态词汇

### 5.1 元数据任务

`queued -> running -> completed | completed_with_warnings | failed`

- `failed` 不自动回到 `queued`。
- 管理员手动重试会创建新尝试并递增 `attempt_no`。
- `completed_with_warnings` 只能由管理员选择失败/缺失的可选阶段重试，不重跑 `javdb_core`。
- 核心元数据已提交后，即使后续可选富化产生 warning，影片仍为 `core_ready`。

### 5.2 缓存任务

`queued -> submitting -> offlining -> resolving -> awaiting_selection | ready -> cleaning -> cleaned`

旁路状态为 `cancelling`、`failed`、`cleanup_failed`、`detached`。`wait_expired` 不是任务状态，只是客户端观察状态。

### 5.3 影片可见性

`raw_only -> metadata_queued -> metadata_running -> core_ready`

只有 `core_ready` 进入媒体库正式卡片、详情页和排行榜展示。图片或翻译缺失通过占位与富化状态表达，不增加新的隐藏状态。

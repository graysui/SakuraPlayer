# SakuraPlayer v1 原始诉求与确认上下文

**记录日期**: 2026-07-24

**状态**: 已确认
**来源**: 用户初始请求、91 轮逐项访谈、AVdb 真实数据核验、`avmedia` 代码与文档分析

## 原始目标

构建一个前后端分离的视频播放软件，后端通过 Docker 部署，客户端覆盖 Windows 桌面端和 HarmonyOS 手机端。系统每天同步 AVdb 资源数据库，对指定分类的影片进行限范围、可续跑的元数据刮削。用户在详情页选择具体资源，系统将资源离线到 115 专属缓存目录，再由内置播放器直接访问 115/CDN 播放。

产品是 `C:\Users\gray9\Desktop\vibecoding\avmedia` 的精简版，但在当前 `player` 仓库从零建立，只选择性移植已经验证的 115、元数据、播放器和基础设施代码，不在旧项目中直接裁剪。

## 冻结的核心选择

- 产品名为 `SakuraPlayer`，首版是单用户、单管理员、单 115 账号的私有工具。
- 首次管理员创建使用 Docker Secret/环境变量提供的一次性初始化口令，远程客户端通过 HTTPS 或可信 VPN 访问。
- Windows 与 HarmonyOS 在登录前配置并测试同一个后端地址；更换地址会注销并清空旧服务端本机状态。
- 先交付 Docker 后端和 Windows 客户端；Windows 稳定后再交付 HarmonyOS API 24 原生客户端。
- 主导航为媒体库、排行榜、女优；另有全局搜索、缓存入口和管理员设置。
- 目标 AVdb 分类为亚洲有码、亚洲无码、中文字幕、4K原版、素人有码、FC2。
- 首次导入上述分类的全部历史资源；首批元数据刮削限制为最近 90 天、最多 5000 个唯一番号。
- 元数据刮削固定并发 3 个任务，不限制队列数量；单任务超过 600 秒强制终止，失败后只能手动重试。
- 用户选择具体资源并点击播放后才创建 115 离线任务。立即执行的任务最多全屏等待 60 秒；未完成时退回客户端，任务继续在 115 后台执行。
- 115 同时运行任务上限为 2，排队上限为 10；就绪缓存默认上限为 20。
- 缓存采用 24 小时滑动 TTL，可设置为 1 小时至 7 天；正在播放的缓存不得清理。
- 播放采用原画直链优先、最高码率 HLS 回退，只支持应用内播放器。
- 影片级进度跨 Windows 和鸿蒙同步，自动续播；不提供独立观看历史页面。
- 不公开上架，Windows 使用私有安装包，鸿蒙使用开发者签名侧载。
- 项目采用 GPLv3，并保留复用代码的许可证和来源说明。

## 已核验的数据事实

2026-07-23 下载并解密的 AVdb 全量快照共有 433,158 条资源帖子，六个目标分类共有 289,858 条。真实字段核验结果包括：

- `亚洲无码 / 无码破解` 子分类有 17,202 条，不能把全部亚洲无码资源都标为破解。
- `中文字幕` 有 50,078 条，其中部分资源同时带有无码破解属性。
- `4K原版` 有 4,193 条，其中 1,685 条明确带有 `有码` 子分类；历史空子分类不能一律推断为有码。
- 目标分类中 243,203 条资源具有正数 `size`，其含义是磁力资源包大小，不保证等于最终视频文件大小。
- 约 2,813 条目标资源没有可用番号，需要进入后台待识别列表。
- GFriends `Filetree.json` 有 318,928 条名称映射和约 279,409 个唯一图片路径；常见名字存在多人歧义，写真匹配必须采用唯一、明确的姓名或别名。

## 明确不在首版范围

- Android、iOS、macOS、Linux、Web 客户端。
- 公开应用商店上架和公网直接暴露后端。
- Nyaa、自定义磁力库、手动磁力输入和通用下载器。
- qBittorrent、Jackett、Indexer、PT/BT 分类、做种和永久媒体库。
- 订阅、自动离线、女优新作推送和多个自定义播放列表。
- 外部播放器、时间轴缩略图、评论、切片、相似推荐和独立观看历史页面。
- 首次启动年龄确认。
- PostgreSQL 和媒体图片的自动备份。

## 已接受的风险

- 不配置自动备份意味着 Docker 卷损坏时，元数据、播放进度、收藏和永久图片可能无法恢复。
- 115、JavDB、DMM、GitHub Raw 和 GFriends 都是外部依赖，协议、限流和可用性可能变化。
- HarmonyOS `AVPlayer` 对固定 User-Agent、302、Range 和 HLS 子请求的一致性必须通过 API 24 SDK 签名核验、构建检查和自动化 fixture 验证后，才能进入鸿蒙实现阶段；不要求连接 API 24 物理真机。
- 项目涉及成人内容、磁力资源和云端离线，使用者负责遵守适用法律、版权要求和 115 服务条款。

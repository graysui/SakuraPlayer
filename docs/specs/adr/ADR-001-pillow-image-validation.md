# ADR-001: 使用 Pillow 验证永久目录图片

**日期**: 2026-07-26
**状态**: Accepted

## 背景

TASK-008 必须验证 JPEG、PNG 和 WebP 的真实格式、完整性、尺寸和总像素。Python 标准库没有覆盖三种格式且能完整解码验证的统一接口，自行解析二进制格式会扩大安全风险。

## 决策

后端固定使用 Pillow 11.2.1 进行图片完整解码、真实格式和像素边界验证。HTTP 下载、主机白名单、字节上限、重定向和原子文件生命周期仍由 SakuraPlayer 适配器控制。

## 后果

- Docker 后端和测试镜像增加一个固定版本依赖。
- provider fixture 可以验证损坏、截断、格式伪装和解压炸弹输入。
- Pillow 不负责 URL 信任、网络请求、路径生成或数据库状态转换。

## 替代方案

- 手写 JPEG/PNG/WebP 解析：实现和安全审计成本过高，拒绝。
- 只信任 `Content-Type` 或文件扩展名：无法识别伪装和损坏内容，拒绝。
- 只保存原始字节不解码：无法执行像素上限，拒绝。
